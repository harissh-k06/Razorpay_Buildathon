# Available Skills
- **explaining**: Explain standardization rules, matching logic, and specific exceptions (Missing Cash vs Unallocated Cash).
- **resolving_editing**: Update CSV data, reassign records, and draft dispute memos.
- **configuring**: Change base currency and adjust matching parameters.
- **reverting_changes**: Revert previously made changes using backup files.
- **viewing_filtering**: Filter and query exceptions (`status_type='exception'` for Missing Cash / High Risk, `status_type='unallocated_cash'` for Extra Cash / Medium Risk) and unallocated cash records.
- **data_schemas**: Detailed structure of standardized CSV files and matching rules.
- **action_log**: Audit trail for all AI actions.
- **master_skills**: Main routing rules, critical financial categories, and safety guardrails for PennyWise.
